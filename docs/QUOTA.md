# سقف پلن رایگان — نه بی‌نهایت

بررسی مستندات Cloudflare (۲۰۲۶-۱۱-۱۳ / اسناد همراه CMS_AGENT):

| منبع | سقف Free تقریبی | رفتار پر شدن |
| --- | --- | --- |
| Workers | ~۱۰۰٬۰۰۰ درخواست/روز در کل حساب، ۱۰ms CPU/invocation | خطای **1027**، ریست ۰۰:۰۰ UTC |
| D1 | ۵M row-read/روز، ۱۰۰k row-write/روز، ۵GB مجموع، ۵۰۰MB/DB | خطا؛ Worker باید **503** بدون draft بدهد |
| Access | تا ۵۰ کاربر | — |
| Cache API | بار D1 را کم می‌کند ولی خود invocation سهمیه می‌خورد | — |

هاست فایل مالک سقف/هزینهٔ جدا دارد.

وقتی سهمیه تمام شود CMS دادهٔ امضانشده سرو نمی‌کند. Android باید cache معتبر و بسته‌های نصب‌شده را نگه دارد. Scale بیشتر = تصمیم مالک برای هزینه یا معماری جدید، نه ارتقای خاموش این Workerها به Paid.
